# 通常の試験の流れ

画面はScoring64 1.2.2より後の版を基準にしている。ボタンや現在の対象を画面で確かめ、名称だけを頼りに操作しない。

## 新規作成・取り込み

- 用紙を新しく作るとき（「東大の理科をA3で」などの依頼を含む）は make-sheet スキルに従う。東大用紙は `?new=1&template=<id>` で1つに決めて開く。
- ホームの「新規」で試験名と用紙を選ぶ。内蔵の東大用紙は「…【編集版】」の名前で並ぶ。既存の解答用紙を使う場合は「解答用紙のPDFを取り込んで始める」または「PDF・教材を開く」からPDFを選ぶ。
- 「作成」タブは、左が部品の追加と選んだ部品の設定（たまにしか変えない項目は「詳細」の中）、中央が紙面、右が問題の一覧。解答欄を設定し、右の一覧の上にある「正解配点」（正解・配点を一覧で入力）と「切出し」（切り出しを一覧で確認）で照合する。紙面の右上の「編集｜PDF」を「PDF」にすると、印刷されるPDFそのものを見られる。番号・氏名欄と解答欄を取り違えない。「正解配点」は先頭の大問だけを表示して開くので、全体にそろえるときは左の一覧で「すべて」を選んでから「一括配点」を使う。
- テンプレートの配点は未設定のことがある。ユーザーの指定と照合し、0点のまま発行しない。記述の模範解答を登録するだけでは自動採点されない。
- 右上の「発行」→「発行」ダイアログの「確定」で、保存・印刷用のPDF作成・確定を順に行い、終わったら「発行」で「取込」タブへ移る。プレビューが「TeXで照合中」「更新中」の間は確定や「用紙を保存」が待ちになるので、連打せず待つ。LuaLaTeXの準備が必要な場合はアプリの案内を読み、ユーザーの利用環境に応じて進める。PDFの取り込みにはTeXは不要。
- 「取込」タブの「発行」欄で配布用PDFを作る。名簿は「名簿CSVを選ぶ」（1行目が見出しの「番号,氏名」または「組,番,氏名」）。読み込むと人数が名簿で決まり、「氏名・生徒番号を事前印字」が自動でオンになる。名簿なしなら「新しく発行する人数」を入れ、「印刷用PDFを作成」。
- 答案PDFは同じタブの「取込」から選ぶ。既に発行済みの答案は対応する試験・用紙版に取り込む。既存のQR付き答案を新しい試験へ取り込まない。
- 同じ試験に同じ中身のPDFがすでに取り込まれていれば（取り込み中を含む）、もう一度選んでも二重には取り込まれず「（ファイル名） は取り込み済みです」と出るだけ。送信が失敗したように見えたら、同じPDFをもう一度選んでよい。前の取り込みが失敗していた場合や、そのPDFのページをすべて除外した場合は取り込み直される。スキャンし直した答案は中身が違うので通常どおり取り込まれ、重なったページは「重複」として選び直す。
- ファイル選択はブラウザ操作ツールのファイルアップロード機能で行う。使えなければユーザーにアプリの画面で選んでもらい、取り込みを確かめてから続ける。

## 採点・訂正

マークの正誤判定・計算はScoring64に任せ、読み取りが曖昧な箇所を原本と照合する。答案の画像には解答欄の周り約3mmも薄く写るので、欄からはみ出した字や隣の欄との取り違えをその場で確かめられる。記述の「部分点」は整数で0点から配点まで。小数の配点・採点基準を受け取った場合は、対応する換算方法を確認する。

答案はスキャン順に並ぶ（生徒番号順ではない）。採点前に、表示された生徒の番号・氏名が対象と一致するか毎回確かめる。

「個別」では採点すると次の答案へ進み、その問題の最後の答案のあとは「次の問題」を押す。「一覧」は自動で進まない。答案を1つずつクリックして選び、その答案のボタンで採点する（採点キーは効かない）。「個別」のキーボード操作はSpace/Enterが満点、Xが0点、Nが次の未採点・要確認。「未完了のみ」にチェックがあると、未採点・要確認の答案だけが並ぶ。「採点」タブを開くとすぐ答案にフォーカスが移るので、タブをクリックした直後からキーが効く（答案をクリックし直さなくてよい）。部分点はPを押し、数字キーで点を打ってEnterで確定する（文字の入力や貼り付けは受け付けない）。入力欄やメニューを操作中に採点キーを送らない。

発行後の「正解訂正」（正解・配点を訂正）は全答案の自動採点に影響する。対象の訂正が依頼されている場合だけ行い、手で付けた点はそのまま残ることを踏まえて確認する。

## 出力

「出力」タブの「ZIP作成」で返却用ZIP（`Scoring64-返却-第N版-日付.zip`）を作る。中身は scores.csv、scores_by_student.csv、生徒ごとのPDF、教師用PDF（成績一覧_教師用.pdf）。ブラウザのダウンロードなので、ファイル名を報告し、保存先を確かめられなければユーザーに尋ねる。未採点を0点として出力しない。出力後に採点を変えた場合は古い出力を返さず、再出力する。バックアップは `.scoring64` 形式。無料の「マークシート読み取り」のCSVはこの出力とは別。
